# 🐍 CIFAR-10 Image Classification with CNN

A deep learning project for **multi-class image classification** on the **CIFAR-10 dataset** using a **Convolutional Neural Network (CNN)** built with **TensorFlow/Keras**.

This project demonstrates a complete computer vision workflow including data loading, preprocessing, CNN modeling, training, evaluation, prediction, and model saving/loading.

## 🍎 Project Objective

The objective of this project is to classify small RGB images into one of the following **10 categories**:

- Airplane
- Automobile
- Bird
- Cat
- Deer
- Dog
- Frog
- Horse
- Ship
- Truck

The project aims to show how a CNN can learn visual patterns from image data and perform **multi-class classification**.

## Dataset Overview

The project uses the **CIFAR-10** dataset.

| Attribute | Description |
|---|---|
| Dataset | CIFAR-10 |
| Total Images | 60,000 |
| Image Size | 32 × 32 pixels |
| Color Channels | RGB (3 channels) |
| Number of Classes | 10 |
| Training Images | 50,000 |
| Test Images | 10,000 |
| Data Format | NumPy arrays / tensors |
| Task | Multi-class image classification |
